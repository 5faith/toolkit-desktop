Formatter 页面重设计 — 3 个方案

所有方案填入相同示例数据，点击卡片打开对应预览页（每个页面均为独立 HTML，可直接用浏览器打开）

方案 A · 紧凑整合 改动最小

保持现有布局骨架，把「格式 Tab + 操作按钮」合并为一行头部；按钮加图标与快捷键提示；INPUT/OUTPUT 面板头增加各自的操作（粘贴/清空、复制/交换）；状态栏增加字符/行数统计。

  • 头部高度从两行压缩为一行，编辑区纵向空间更大
  • 主操作 Format 高亮为强调色按钮，层级更清晰
  • 面板级操作就近放置，减少鼠标移动距离

方案 B · 卡片软风 视觉升级

现代化 SaaS 风格：圆角卡片面板、面板间隙与柔和阴影、渐变强调色、侧栏激活项改为圆角胶囊。含右上角「浅色 / 深色」切换，可预览两种主题效果。

  • 面板圆角 + 间隙，弱化生硬的分隔线
  • Format 改为渐变主按钮，次要操作改为图标按钮
  • 侧栏与状态栏同步软化为圆角风格

方案 C · IDE 专业风 高密度

面向重度用户的高密度布局：编辑器带行号 Gutter、错误/校验横幅、可拖拽分隔条（含居中交换按钮）、底部状态面板显示统计与快捷键速查，整体信息密度最高。

  • 行号 + 等宽字体，接近 VS Code 编辑体验
  • 校验结果以横幅形式常驻显示，不用弹 Toast
  • 分隔条中部嵌入交换按钮，底部面板常驻统计
